# Подготовка SEO и веб-аналитики AI PROFI

## Действующие настройки
- Боевой домен: \`https://ai-profi.pro\`. NEXT_PUBLIC_SITE_URL теперь по умолчанию указывает на него.
- robots.txt, метатеги robots и sitemap.xml подчинены переменной SITE_READY_FOR_INDEXING. До снятия ограничителя **noindex / Disallow: /** сохранён.
- Индивидуальные метаданные, canonical и sitemap предусмотрены для каталога и отдельных сценариев.
- Яндекс Метрика: загрузка после согласия посетителя; \`NEXT_PUBLIC_YANDEX_METRIKA_ID\` пока не указан в Vercel (проверено на 24.11.2026).

## Что требуется от владельца
1. Утвердить актуальную политику персональных данных, необходимые сведения об операторе, проверить требования к передаче данных через сторонние сервисы. Сценарии и тексты согласовать до индексации.
2. Создать или подключить счётчик Яндекс Метрики для \`ai-profi.pro\`, передать только **числовой ID** в Vercel Production Env \`NEXT_PUBLIC_YANDEX_METRIKA_ID\`. Не включать запись сеансов до отдельной проверки согласий.
3. Добавить \`https://ai-profi.pro\` в Яндекс Вебмастер и в Google Search Console, подтвердить право на домен (DNS или официальные коды). Для HTML-подтверждения предусмотрены \`YANDEX_SITE_VERIFICATION\` и \`GOOGLE_SITE_VERIFICATION\` в Vercel.
4. Проверить тестовые события Метрики и исключить передачу ФИО, контактов, текста запросов и других персональных данных в параметры событий.
5. После полноценной проверки и завершения правовой подготовки включить \`SITE_READY_FOR_INDEXING=true\`, передать sitemap \`https://ai-profi.pro/sitemap.xml\` в поисковые кабинеты, проверить robots и canonical.
6. Установить \`NEXT_PUBLIC_SITE_URL=https://ai-profi.pro\` в Vercel (резервное значение уже исправлено в коде). Изменения переменных сборки требуют нового развёртывания.

## События Метрики
- \`catalog_open\` — нажатие на карточку сценария; параметры slug/category.
- \`demo_select\` — выбор демонстрационного сценария; параметр scenario.
- \`demo_result\` — открытие условного результата.
- \`contact_open\` — попытка открыть канал (показывается капча).
- \`contact_verified\` — успешно пройдена проверка контакта.
- \`contact_click\` — пользователь переходит в мессенджер или запускает почту.

**Ни одно из этих событий не означает состоявшийся лид или договор.** Конверсию в квалифицированное обращение и деньги необходимо учитывать из реальной CRM/реестра, а не создавать ложный event conversion.

В Яндекс Метрике для нужных событий создать цели «JavaScript-событие» с точно такими идентификаторами. Метод \`reachGoal\` выполняется только после принятия согласия.

- автоматизация crm нейросети

- автоматизация сверки документов
- распознавание накладных нейросеть
- контроль дебиторки 1с отчёт
- нейросеть анализ отзывов маркетплейсы
- прогноз закупок sku маркетплейсы
- анализ маржинальности товаров озон вайлдберриз
- сравнение коммерческих предложений поставщиков ии
- ии анализ договоров сравнение редакций
- нейросеть для тендерной документации
- ии для технической документации поиск
- компьютерное зрение контроль качества производства
- нейросеть сервисный центр заявки

## Контроль качества публикаций
- Сценарий отличается решаемой проблемой, используемыми данными и механизмом решения.
- Нет неподтверждённых заявлений «выполнено», «экономия 80%», фейковых отзывов, логотипов или отзывов.
- Риски и необходимость человеческого контроля обозначены.
- Рабочие ссылки, отдельный title/description, корректный canonical.
- Редактура человеком и перепроверка отраслевых допущений.
- Измеряем просмотры и осмысленные обращения; не создаём десятки дублей под перестановки слов.
