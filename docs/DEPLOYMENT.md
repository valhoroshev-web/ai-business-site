# Запуск сайта AI PROFI

## 1. Где находится проект

- GitHub: https://github.com/valhoroshev-web/ai-business-site
- Vercel: https://vercel.com/valhoroshev-web/ai-business-site
- Публичный адрес: https://ai-business-site-tau.vercel.app

Проект — Next.js. Изменения ветки main автоматически развёртываются Vercel.

## 2. Что работает без дополнительных сервисов

- Русскоязычная главная страница B2B-услуг;
- меню с мобильной навигацией;
- адаптивные карточки услуг, сценариев и интеграций;
- базовые SEO title, description, Open Graph;
- технические маршруты robots.txt и sitemap.xml;
- заглушка формы до подключения и утверждения политики данных.

Форма намеренно не принимает персональные данные, пока конфигурация не завершена.

## 3. Telegram для заявок

1. В Telegram откройте официальный @BotFather и создайте бота командой /newbot.
2. Отправьте созданному боту /start со своего аккаунта.
3. Узнайте идентификатор чата (chat.id) в ответе Telegram Bot API getUpdates. НЕ отправляйте токен бота, URL с токеном или личные данные в чаты поддержки и ChatGPT.
4. Откройте Vercel → ai-business-site → Settings → Environment Variables.
5. Добавьте TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID в Production как секреты.
6. Для обеспечения защиты формы настройте Turnstile (ниже).
7. Убедитесь, что Telegram API разрешён для выбранного размещения и что передача данных соответствует применимому законодательству.

Серверная отправка реализована в src/app/api/leads/route.ts.
Если Telegram не подтверждает успешную отправку, сайт не сообщает посетителю, что заявка доставлена.

## 4. Cloudflare Turnstile

1. Создайте виджет Turnstile в Cloudflare с доменом ai-business-site-tau.vercel.app (и любым планируемым доменом).
2. Получите Site Key и Secret Key.
3. Добавьте в Vercel:
   - NEXT_PUBLIC_TURNSTILE_SITE_KEY — публичный ключ;
   - TURNSTILE_SECRET_KEY — секретный ключ.

Проверка выполняется сервером через Siteverify. Одного виджета в браузере недостаточно.

## 5. Оператор персональных данных

Перед включением формы оператор должен определить правовой режим обработки, фактическое место размещения и передачи данных, сроки хранения, основания для обработки и утверждённую политику.

Только после юридической проверки и заполнения реальных реквизитов добавьте:
- LEGAL_OPERATOR_NAME — полное наименование/ФИО оператора;
- LEGAL_OPERATOR_ADDRESS — адрес;
- LEGAL_CONTACT_EMAIL — контакт для запросов о данных.

Раздел /privacy содержит предварительный текст, который НЕ заменяет юридически проверенную политику. При необходимости замените его итоговой редакцией.

И только после всех предыдущих действий:
- LEADS_ENABLED=true

Включение формы требует одновременно:
LEADS_ENABLED=true + Telegram ключи + Turnstile ключи + данные оператора.

Не вносите токены в GitHub. Значения хранятся в Vercel Environment Variables.

## 6. Яндекс Метрика

1. В Яндекс Метрике создайте счётчик для своего адреса сайта.
2. Скопируйте цифровой номер счётчика.
3. Добавьте в Vercel NEXT_PUBLIC_YANDEX_METRIKA_ID.
4. В Метрике создайте цель типа «JavaScript-событие» с идентификатором lead_submitted.
5. После обновления развёртывания проверьте согласие посетителя, загрузку счётчика и достижение цели после успешной заявки.

До согласия посетителя Метрика не загружается.

## 7. SEO и индексация

В исходном состоянии SITE_READY_FOR_INDEXING=false (или переменная отсутствует).
Тогда metadata запрещает индексирование, а robots.txt запрещает обход.
Это предохраняет от публикации демонстрационных и юридически неготовых страниц.

Перед запуском поискового продвижения:
- утвердите бренд, домен и контакты;
- удалите демонстрационные остатки или создайте реальные страницы;
- проверьте право на обработку заявок;
- настройте канонический домен и HTTPS;
- задайте NEXT_PUBLIC_SITE_URL=https://ВАШ-ДОМЕН;
- включите SITE_READY_FOR_INDEXING=true;
- выполните redeploy и проверьте sitemap.xml, robots.txt, заголовки, доступность;
- добавьте сайт в панели Яндекс Вебмастера и Google Search Console, если они нужны.

## 8. Обновление конфигурации

В Vercel изменения переменных окружения применяются только после нового развёртывания (Redeploy).

После настройки:
1. Отправьте тестовую заявку с собственными тестовыми данными.
2. Убедитесь, что уведомление действительно получено в Telegram.
3. Проверьте отправку без Turnstile, с ошибочным кодом и без согласия: эти запросы должны отклоняться.
4. Проверьте цель lead_submitted в Яндекс Метрике.
5. Проверьте внешний вид на телефоне и компьютере.

Сервис не хранит заявки в базе данных: первая версия передаёт их только в Telegram. Для отказоустойчивости и CRM потребуется отдельное хранилище/интеграция.
