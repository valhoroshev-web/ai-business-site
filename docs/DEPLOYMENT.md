# AI PROFI: публикация и настройка

## Проект

- Репозиторий: https://github.com/valhoroshev-web/ai-business-site
- Vercel: https://vercel.com/valhoroshev-web/ai-business-site
- Домен: https://ai-profi.pro
- Резервный адрес: https://ai-business-site-tau.vercel.app

Сайт развёртывается автоматически из ветки `main`. Основной способ связи с клиентами — **две иконки Telegram и электронной почты**. Собственная форма заявок удалена; серверного API для сбора заявок на сайте нет.

## Контакты после CAPTCHA

В разделе `/#contact` и в подвале показаны две карточки: Telegram и конверт. После нажатия клиент получает простой математический вопрос. Если ответ верный, сервер возвращает ссылку Telegram или адрес электронной почты. Секрет и контактные данные не входят в HTML, клиентский JavaScript и открытый код репозитория.

В **Vercel → Project → Settings → Environment Variables → Production** должны быть заданы:

- `CONTACT_TELEGRAM_USERNAME` — Telegram-ник без символа `@`;
- `CONTACT_EMAIL` — адрес для прямых писем;
- `CONTACT_CAPTCHA_SECRET` — секрет для подписывания проверок, не менее 24 символов, предпочтительно криптографически случайный.

Эти три переменные уже были настроены через подключение Vercel. Не помещайте их значения в GitHub или публичные страницы.

После изменения переменных требуется **Redeploy**.

### Как проверять

1. Откройте `https://ai-profi.pro/#contact`.
2. Нажмите Telegram, решите пример — должен открыться Telegram-чат.
3. Нажмите иконку почты, решите пример — должны появиться адрес и кнопка создания письма.
4. Неверный ответ или токен старше пяти минут не должны раскрывать контакт.
5. Проверьте поведение на мобильном устройстве.

**Ограничение:** простая CAPTCHA затрудняет сбор контактов примитивными ботами, но целенаправленный бот может решить пример. Для более сильной защиты стоит добавить ограничение частоты запросов на уровне WAF и наблюдать за аномалиями.

## Аналитика

`NEXT_PUBLIC_YANDEX_METRIKA_ID` — номер счётчика. Яндекс Метрика загружается только после согласия посетителя. Удаление формы означает, что цель `lead_submitted` больше не используется; при необходимости следует измерять отдельно нажатия на иконки и успешные проверки.

## Юридические документы

Страница `/privacy` пока содержит предварительную редакцию. Отсутствие формы не отменяет обязанностей по защите данных: посетитель может передать свои сведения через Telegram или электронную почту, а платформа сайта получает технические сведения о запросах. Перед полноценным коммерческим запуском требуется проверить применимое законодательство, установить реквизиты оператора и утвердить политику.

В Vercel предусмотрены переменные:
- `LEGAL_OPERATOR_NAME`;
- `LEGAL_OPERATOR_ADDRESS`;
- `LEGAL_CONTACT_EMAIL`;
- `LEGAL_POLICY_APPROVED`.

Не устанавливайте `LEGAL_POLICY_APPROVED=true` до фактического утверждения документа. При необходимости раскрытия законодательно обязательных контактов предусмотрите отдельный рабочий адрес, а не личный Gmail.

## SEO

`SITE_READY_FOR_INDEXING` по умолчанию `false`. До включения индексации проверьте HTTPS, актуальные контакты, коммерческий контент, юридические документы и домен, а затем:

- установите `NEXT_PUBLIC_SITE_URL=https://ai-profi.pro`;
- включите `SITE_READY_FOR_INDEXING=true`;
- выполните Redeploy;
- проверьте `robots.txt`, `sitemap.xml`, canonical и четыре страницы услуг.

Не включайте индексацию автоматически только потому, что сайт опубликован.
