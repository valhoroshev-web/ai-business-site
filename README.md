# AI Business

Коммерческий сайт услуг ИИ-автоматизации бизнеса на базе открытого шаблона [Startup — Next.js](https://github.com/NextJSTemplates/startup-nextjs).

## Текущее содержание

- Русскоязычный адаптивный лендинг
- ИИ-операторы, ИИ-агенты, интеграции с 1С и CRM
- Примеры сценариев, этапы внедрения, вопросы
- Серверная отправка заявок в Telegram (после настройки)
- Cloudflare Turnstile (после настройки)
- Яндекс Метрика с предварительным согласием посетителя (после настройки)
- Базовые SEO-метаданные, robots.txt и sitemap.xml
- GitHub Actions для проверки сборки при Pull Request

**Внимание:** форма заявок и поисковая индексация по умолчанию отключены до завершения юридической и технической настройки. Не включайте их без реальных реквизитов оператора данных и подтверждённого приёма заявок.

## Запуск локально

Требуется Node.js 22 или совместимая версия.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Публикация и настройка

Проект разворачивается через Vercel из ветки `main`. Полная инструкция по подключению Telegram, Cloudflare Turnstile, Яндекс Метрики, безопасности, настройке переменных окружения и включению SEO:

**[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)**

Пример переменных окружения: [`.env.example`](.env.example). Никогда не помещайте реальные секреты в GitHub.
