# AI PROFI

Коммерческий сайт AI PROFI — услуги ИИ-автоматизации бизнеса на базе открытого шаблона [Startup — Next.js](https://github.com/NextJSTemplates/startup-nextjs).

## Текущее содержание

- Русскоязычный адаптивный лендинг
- ИИ-операторы, ИИ-агенты, интеграции с 1С и CRM
- Примеры сценариев, этапы внедрения, вопросы
- Прямые контакты Telegram и электронной почты через иконки и проверку CAPTCHA
- Отсутствие встроенной формы заявки — общение через привычные клиенту каналы
- Яндекс Метрика с предварительным согласием посетителя (после настройки)
- Базовые SEO-метаданные, robots.txt и sitemap.xml
- GitHub Actions для проверки сборки при Pull Request

**Внимание:** поисковая индексация по умолчанию выключена до юридической и технической готовности сайта. Собственная форма заявок удалена.

## Запуск локально

Требуется Node.js 22 или совместимая версия.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Публикация и настройка

Проект разворачивается через Vercel из ветки `main`. Полная инструкция по настройке защищённых ссылок Telegram и почты, Яндекс Метрики, переменных окружения и индексации:

**[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)**

Пример переменных окружения: [`.env.example`](.env.example). Никогда не помещайте реальные секреты в GitHub.
